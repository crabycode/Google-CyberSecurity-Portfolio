# Google Cybersecurity Portfolio

This repository contains hands-on cybersecurity labs and practical activities completed during the **Google Cybersecurity Professional Certificate** program.
All projects were completed between **September 2025 – December 2025** and later reviewed, corrected, and organized before being uploaded to this repository.

---

## About

This portfolio demonstrates foundational cybersecurity skills developed through practical exercises and scenario-based investigations.
The activities focus on real-world analyst tasks such as:
- Security incident analysis
- Risk and vulnerability assessments
- Network traffic analysis
- Access control and hardening
- Linux and SQL investigations
- Phishing detection and SOC workflows
- Security documentation and reporting
Each folder contains project files, reports, worksheets, or supporting materials created during the course.

---
